🔧 How to Set Up Firebase Realtime Database

  1. Go to Firebase Console → Create a project
  2. Click Build → Realtime Database → Create Database
  3. Start in test mode
  4. Go to Project Settings ⚙️ → General → Your apps → Web app (</>)
  5. Register your app and copy the entire firebaseConfig object
  6. Paste it into both index.html and admin.html
  7. Save both files, then open admin.html

💡 Demo mode: The site works with beautiful default images and data even without Firebase configured. Once you add Firebase, admin saves will persist permanently.
