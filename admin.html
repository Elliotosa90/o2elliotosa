🔧 How to Set Up Firebase Realtime Database

  1. Go to Firebase Console and click Create a project (or use an existing one).
  2. In your project, click Build > Realtime Database > Create Database.
  3. Start in test mode (this allows read/write from anyone — fine for now).
  4. Go to Project Settings ⚙️ > General > Your apps > Web app (the </> icon).
  5. Register your app and copy the entire firebaseConfig object.
  6. Paste it into both index.html and admin.html (look for const firebaseConfig = { ... }).
  7. Save both files, then open admin.html — you should see "Connected to Firebase".

💡 Security Note: Test mode allows anyone to read/write. Once everything works, update your Firebase Realtime Database Rules for production.
